BRIDGEAI ZERO 2 TRANSFORMER

벡터는 숫자의 묶음, 행렬은 여러 벡터의 묶음

문장에 토큰이 5개 있고 토큰 하나를 8차원으로 표현한다면 문장 하나의 표현은 5 × 8입니다. 문장 2개를 같은 길이로 모으면 2 × 5 × 8 tensor가 됩니다. 숫자 배열에 붙인 각 축의 의미가 중요합니다. [42 · Ch.2]

표기 읽는 법 예시
scalar 수 하나 손실 0.42
vector 한 축의 배열 토큰 하나의 특징 8개
matrix 두 축의 배열 토큰 5개 × 특징 8개
tensor 여러 축을 가진 배열 Batch × Head × Query × Key
transpose 두 축의 순서를 교환 (N,d) → (d,N)

내적은 비교 점수를 만든다

q ⊤ k = ∑ r = 1 d q r k r

예를 들어 q=(1,2), k=(3,−1)이면 내적은 1입니다. 내적은 방향과 크기에 영향을 받습니다. 내적 점수를 cosine similarity와 항상 같은 것으로 말하면 안 됩니다.

cos ( q , k ) = q ⊤ k ‖ q ‖ ‖ k ‖

Q가 (N,d), K가 (M,d)이면 QKᵀ는 (N,M)입니다. Q의 각 행과 K의 각 행이 한 번씩 비교됩니다. 행렬 곱은 가능한 모든 Query–Key 쌍의 점수를 한꺼번에 계산하는 표기입니다.

Softmax는 점수를 양의 비중으로 바꾼다

p i = exp ⁡ ( z i ) ∑ j exp ⁡ ( z j )

값들이 합쳐서 1이 되지만, 이것이 예측이 현실적으로 잘 보정된 확률이라는 보장은 아닙니다. 수치적으로는 최댓값을 빼도 결과가 같아 overflow를 줄일 수 있습니다.

softmax ( z ) i = exp ⁡ ( z i − max ( z ) ) ∑ j exp ⁡ ( z j − max ( z ) )

Temperature τ > 0에 대해 softmax(z/τ)를 쓰면 같은 순서를 유지하면서 분포의 뾰족함을 바꿀 수 있습니다. Attention의 √d 스케일과 생성 시 temperature는 위치와 목적이 다릅니다.

미분과 연쇄법칙: 어떤 값이 손실을 바꾸었나

∂ L ∂ w = ∂ L ∂ y ^ ∂ y ^ ∂ w

예시로 ŷ=wx, L=½(ŷ−y)²를 놓으면 ∂L/∂w=(wx−y)x입니다. x=2, y=6, w=1이면 gradient는 −8입니다. 학습률 0.1에서 한 번 업데이트하면 w=1.8이 되어 예측은 3.6으로 이동합니다. 음수 gradient에 다시 음수를 곱하므로 파라미터가 증가한다는 점을 직접 계산합니다.

정보를 잰다는 것: Entropy와 Cross-entropy

H ( p ) = − ∑ i p i log ⁡ p i , H ( q , p ) = − ∑ i q i log ⁡ p i

Entropy는 분포가 얼마나 퍼져 있는지, Cross-entropy는 정답 분포 q에 대해 예측 p가 얼마나 큰 로그 손실을 내는지를 표현합니다. One-hot 정답에서는 Cross-entropy가 −log p(정답)으로 단순해집니다. Attention entropy가 낮다는 사실만으로 “중요한 것을 잘 골랐다”고 결론 내릴 수는 없습니다. [42 · Ch.3]

단순한 이진 Perceptron의 예측을 1[wᵀx+b ≥ 0]로 놓으면, 2차원 입력의 결정 경계는 직선입니다. AND·OR 같은 간단한 관계는 가능하지만, XOR의 양성 두 점과 음성 두 점은 대각선으로 엇갈려 한 직선으로 완전히 분리할 수 없습니다. 이는 해당 모델 클래스의 표현력 제약입니다. [04] [42 · Ch.6]

AlexNet은 대규모 데이터, GPU 계산, CNN, 비선형성, 데이터 증강과 정규화가 함께 작동하는 사례입니다. Deep Belief Network는 깊은 모델을 학습시키기 위한 또 다른 역사적 접근입니다. 표현력은 충분해도 학습·데이터·자원이 부족하면 그 표현을 얻지 못할 수 있습니다. [13] [12]

Residual과 정규화의 문제의식

y = x + F ( x )

잔차 연결은 기존 표현에 변화량을 더하는 경로를 만듭니다. Pre-LN 형태의 단순 잔차 경로에서 Jacobian은 I+∂F/∂x로 표현되어 identity 경로의 존재를 볼 수 있습니다. 그러나 원형 Transformer의 Post-LN은 뒤에 LN이 있으므로 전체 미분을 그대로 I+∂F/∂x라고 하면 안 됩니다. [19] [25]

문자열을 토큰으로 나누고 각 토큰에 정수 ID를 배정합니다. ID가 100이라고 해서 ID 10보다 의미가 열 배 큰 것은 아닙니다. ID는 lookup을 위한 주소이고, 학습 가능한 벡터가 실제 계산에 들어갑니다. [11]

One-hot 행 벡터를 E에 곱하는 것과 해당 행을 lookup하는 것은 수학적으로 같습니다. 실제로 큰 One-hot tensor를 만들 필요는 없습니다.

단어 단위는 직관적이지만 어휘가 커지고 처음 보는 단어를 다루기 어렵습니다. 문자·byte·subword는 다른 절충점을 가집니다. 예를 들어 unhappiness → un + happi + ness는 분할을 설명하기 위한 예시이며, 특정 tokenizer의 실제 결과를 주장하지 않습니다. [23]

Word2Vec에서 배울 것

주변 문맥을 이용해 표현을 학습하면, 데이터에서 비슷한 문맥에 나타나는 단어들이 관련된 표현을 얻을 수 있습니다. CBOW는 문맥으로 중심 단어를, Skip-gram은 중심 단어로 주변 단어를 예측하는 방식으로 이해합니다. 특정 벡터 차원이 사람이 붙인 의미와 일대일 대응할 필요는 없습니다. [14]

기본적인 정적 단어 임베딩은 같은 단어에 같은 초기 벡터를 줍니다. river bank와 bank account의 bank가 문맥에 따라 달라져야 한다면 문맥을 처리한 뒤의 표현이 필요합니다. Transformer에서는 그 역할을 이후 블록들이 수행합니다.

문장을 생성하는 것은 조건부 확률의 연결

p ( y 1 , … , y T ) = ∏ t = 1 T p ( y t ∣ y < t )

번역처럼 입력 x가 있으면 각 항에 x를 추가로 조건화합니다.

p ( y ∣ x ) = ∏ t = 1 T p ( y t ∣ y < t , x )

훈련 데이터 문장에서 이전 토큰과 다음 토큰 쌍을 만들면 자기지도학습이 됩니다. 이 확률 분해가 RNN만의 성질은 아닙니다. 확률 모델의 목표와 그것을 계산할 아키텍처를 분리해야 합니다. [11] [16]

Contextual representation은 어디에서 달라질까

Embedding 직후의 같은 토큰은 같은 lookup 벡터를 가질 수 있습니다. 위치 정보가 더해지고 주변 입력을 참조하면 각 위치의 출력 표현이 달라집니다. “단어 의미가 모두 Embedding 표 안에 저장된다”보다 lookup과 문맥 계산이 함께 표현을 만든다고 이해하는 편이 정확합니다.

토큰화 실습을 진행할 때의 주의점

실제 tokenizer를 쓰는 실습과 문자 단위의 교육용 tokenizer를 명확하게 표시합니다. 한국어 한 문장을 여러 tokenizer로 비교할 때도 ID 숫자 크기나 토큰 수만으로 품질을 평가하지 않습니다. 동일 corpus·목표에서 비용과 성능을 비교해야 합니다.

왜 위치 정보가 필요한가

위치 정보나 위치 의존 mask가 없는 Self-attention에 입력 순열 P를 적용해 봅시다. Q′=PQ, K′=PK, V′=PV입니다. 행 단위 Softmax는 행·열의 대응 순열과 함께 움직이므로 다음이 성립합니다.

S A ( P X ) = softmax ( P Q K ⊤ P ⊤ / d h ) P V = P softmax ( Q K ⊤ / d h ) V = P S A ( X )

이는 순열 등변성입니다. 입력을 섞으면 출력도 같은 방식으로 섞입니다. 출력이 변하지 않는다는 순열 불변성과 다릅니다. Mean pooling 같은 순열 불변 집계까지 붙였을 때 최종 결과가 같아지는 경우를 별도로 생각할 수 있습니다.

“Sin/cos가 정답”은 아니다

위치 단서가 필요하다는 주장과 특정 함수가 필수라는 주장은 다릅니다. 원논문에서도 학습형 위치 임베딩과 비교했습니다. 고정 함수가 더 긴 길이에 값을 계산할 수 있다는 사실만으로 훈련보다 긴 길이에 잘 일반화한다는 보장은 생기지 않습니다. [22 · §3.5]

Causal mask가 있으면 이미 방향과 경계에 대한 구조적 정보가 생기므로, 위 등변성 증명을 그대로 적용할 수 없습니다. “Positional encoding을 지우면 모든 Transformer가 완전히 순서를 모른다”처럼 mask의 존재를 무시하지 않습니다.

Self-attention이라고 Q=K=V는 아니다

원본 X가 같더라도 W_Q,W_K,W_V가 다르면 값이 다릅니다. QKᵀ도 일반적으로 대칭이 아닙니다. “A가 B를 보는 비중”과 “B가 A를 보는 비중”은 다를 수 있습니다. 설령 Q=K로 점수 행렬이 대칭이어도, 행마다 정규화하는 Softmax 이후에는 일반적으로 대칭이 아닙니다.

왜 점수용과 내용용 벡터를 나눌까

비교 기준과 가져올 특징을 같은 좌표계로 묶지 않을 수 있습니다. 어떤 특징으로 다른 토큰을 찾을지와, 그 토큰에서 어떤 정보를 전달할지를 따로 학습하는 자유를 줍니다. 이것은 표현을 설계하는 선택이지, 각 축이 미리 “주어”, “동사”, “중요도”로 지정되었다는 뜻은 아닙니다.

Cross-attention에서는 출처가 바뀐다

Q = D W Q , K = E W K , V = E W V

D는 Decoder 쪽 T개 위치, E는 Encoder 쪽 S개 위치의 표현입니다. 따라서 점수 행렬은 T×S이고, 출력 위치 수는 Query 수 T입니다. Cross-attention을 한다고 source 길이 S로 출력 길이가 바뀌지 않습니다. [28]

Q/K/V 설명에서 흔한 오개념

“Query가 중요한 토큰을 찾는다”에서 멈추면 목적 함수와 중요도를 혼동합니다. 실제로는 학습된 내적 점수로 가중합을 만들며, 그 결과가 최종 loss를 줄이는 방향으로 학습됩니다. 중요도라는 말은 어떤 평가 기준의 중요도인지 정의한 뒤 사용하게 합니다.

고정한 Key·Value와 현재 Query 보기

왜 √dₕ로 나눌까

단순화한 가정으로 q,k의 성분이 서로 독립이고 각각 평균 0, 분산 1이라고 합시다. 이때 내적 합의 분산은 dₕ입니다.

Var ( ∑ r = 1 d h q r k r ) = d h , Var ( q ⊤ k d h ) = 1

차원이 커지면서 점수 크기가 커져 Softmax가 지나치게 뾰족해지는 현상을 완화하려는 스케일입니다. 실제 학습된 Q/K가 항상 이 가정을 만족하거나 분산이 정확히 1이라는 주장은 아닙니다. [22 · §3.2.1]

높은 가중치는 어디에 적용되나

가중치 αⱼ가 크면 해당 Vⱼ의 기여 비중이 커집니다. 하지만 V의 크기와 방향이 다르므로, 가중치 숫자 하나만으로 최종 출력 변화량을 전부 알 수는 없습니다. 뒤에는 W_O, residual, FFN과 다음 층도 있습니다. Attention heatmap은 유용한 관찰 도구이지만, 최종 예측의 인과적 설명과 같지는 않습니다. [39] [40]

중요한 경계 조건

모든 Key가 가려진 행에서는 Softmax의 정상적인 확률 분포가 정의되지 않습니다. 구현에 따라 NaN·0 등 처리가 달라질 수 있으므로, 유효한 Query에는 적어도 하나의 허용 Key가 있도록 입력과 mask를 설계합니다. 또한 Attention dropout 이후에는 개별 행의 합이 정확히 1일 필요가 없습니다. 단위 테스트는 dropout을 끄거나 적용 전 A를 검사합니다. [27]

y = x + Dropout ( F ( x ) )

LayerNorm은 어느 축을 정규화할까

토큰 하나 x∈ℝᵈ에서 평균과 분산을 구합니다. (B,N,d) 입력의 전형적인 LayerNorm(d)는 마지막 d축을 정규화합니다. Batch와 sequence 전체를 한꺼번에 정규화하지 않습니다. [20] [30]

μ = 1 d ∑ r = 1 d x r , σ 2 = 1 d ∑ r = 1 d ( x r − μ ) 2
LN ( x ) = γ ⊙ x − μ σ 2 + ϵ + β

γ,β는 학습 가능한 scale·shift입니다. ε는 0으로 나누는 수치 문제를 완화합니다. 기본 정규화 뒤 γ,β가 적용되므로 최종 출력이 항상 평균 0·분산 1일 필요는 없습니다. 또한 LayerNorm의 학습 가능한 파라미터는 입력 token마다 별개가 아니라 해당 모듈의 특징 축에 공유됩니다.

Post-LN과 Pre-LN은 배치 순서가 다르다

Post-LN : y = LN ( x + F ( x ) )
Pre-LN : y = x + F ( LN ( x ) )

원형은 Post-LN입니다. Pre-LN은 정규화를 sublayer 입력 안으로 옮기며, stack 끝에 별도의 최종 Norm을 두는 경우가 많습니다. 정규화 위치는 초기 gradient와 학습 안정성에 영향을 줍니다. 비교할 때 optimizer·학습률·warm-up·깊이도 통제합니다. [25]

FlashAttention은 tile 단위 계산과 메모리 계층에 맞춘 재사용으로, 거대한 Attention 표 전체를 HBM에 물리적으로 저장하지 않고 같은 Dense Attention을 계산합니다. 정확한 Attention을 더 IO 효율적으로 계산하는 것과 Dense 상호작용의 산술량을 선형으로 바꾸는 것은 다릅니다. [38]

경로 길이와 계산 의존성

RNN에서는 먼 두 위치 사이 정보가 여러 시간 step을 거칩니다. Global Self-attention은 한 층에서 모든 위치를 직접 연결할 수 있습니다. CNN은 수용 영역·stride·dilation에 따라 필요한 경로가 달라집니다. 짧은 경로가 원하는 의미 관계를 반드시 잘 학습한다는 보장은 아닙니다. [22 · §4]

KV Cache의 저장량

길이 N, L개 층, KV Head 수 H_kv, Head 차원 dₕ, 원소당 b bytes인 자기회귀 모델의 단순 KV 저장량은 다음과 같습니다. K와 V를 각각 저장하므로 2가 붙습니다.

bytes K V = 2 B L N H k v d h b

MHA에서는 H_kv=H이며 GQA에서는 더 적은 KV Head를 공유할 수 있습니다. 이 식은 순수 K/V 데이터만의 크기이고 allocator·padding·block metadata 등 추가 비용은 포함하지 않습니다. [37]

실험 측정에서 통제할 것

동일 batch·dtype·sequence length·생성 길이·device·kernel·warm-up 조건을 기록합니다. GPU timing에서는 비동기 실행 때문에 적절한 동기화가 필요합니다. Parameter 감소율, FLOPs 감소율, 실제 latency 감소율은 서로 같지 않습니다. 품질–지연–메모리의 trade-off를 함께 보고합니다.

RESEARCH LENS

토큰을 절반으로 줄이면 Attention 곱셈 항은 약 1/4, 투영·FFN 항은 약 1/2가 됩니다. 그러나 pruning 자체의 overhead, 실제 kernel 모양, 데이터 이동, 다른 모듈의 고정비 때문에 전체 지연이 같은 비율로 줄지는 않습니다. 비율은 식으로 예측하고, 실행 시간은 별도로 측정합니다.

연산량 계산기에서 반드시 물어볼 질문

d를 고정하고 N을 두 배로 만들었을 때 항마다 몇 배가 되는지 먼저 쓰게 합니다. 다음에는 N을 고정하고 d를 두 배로 바꿉니다. Head 수 변경이 산술량과 explicit score 저장량에 다르게 작용하는 것을 확인합니다. 예측 지연 시간은 계산기에 넣지 않습니다.

#!/usr/bin/env python3
"""AI Zero 2 Transformer — self-contained PyTorch teaching lab.

Checks: python transformer_lab.py --mode check
Train:  python transformer_lab.py --mode train --steps 400 --device cpu

Task: reverse a sequence of integers. No external dataset or model download.
Architecture: small Post-LN encoder-decoder, sinusoidal positions, explicit MHA.
Not a reproduction of the original paper's size, training recipe, or metrics.
No KV cache: generation recomputes the target prefix for readability.
Dependency: PyTorch. Tested on CPU with PyTorch 2.10.0.
"""
from __future__ import annotations

import argparse
import json
import math
import random
from pathlib import Path
from typing import Optional

import torch
from torch import Tensor, nn
from torch.nn import functional as F

PAD, BOS, EOS, VOCAB = 0, 1, 2, 16


def attention(q: Tensor, k: Tensor, v: Tensor,
              allow: Optional[Tensor] = None, *,
              dropout_p: float = 0.0, training: bool = False) -> tuple[Tensor, Tensor]:
    """q/k/v: [B,H,T or S,D]. allow: broadcastable bool mask, True=allowed.

    Returns the weighted values and PRE-DROPOUT probabilities.
    Valid queries must have at least one allowed key.
    """
    if q.ndim != 4 or k.ndim != 4 or v.ndim != 4:
        raise ValueError('q, k, v must be rank-4 tensors [B,H,T,D].')
    if q.shape[-1] != k.shape[-1] or k.shape[-2] != v.shape[-2]:
        raise ValueError('Incompatible query/key dimensions or key/value lengths.')
    scores = (q @ k.transpose(-2, -1)) / math.sqrt(q.size(-1))
    if allow is not None:
        if allow.dtype != torch.bool:
            raise TypeError('allow must be boolean: True means allowed.')
        # This check is useful in teaching code, but may sync the GPU.
        if not bool(allow.any(dim=-1).all()):
            raise ValueError('Every query row must have at least one allowed key.')
        scores = scores.masked_fill(~allow, float('-inf'))
    weights = scores.softmax(dim=-1)
    dropped = F.dropout(weights, p=dropout_p, training=training)
    return dropped @ v, weights


class MultiHead(nn.Module):
    def __init__(self, d: int, heads: int, dropout: float = 0.0) -> None:
        super().__init__()
        if d % heads:
            raise ValueError('d must be divisible by the number of heads.')
        self.heads, self.dh = heads, d // heads
        self.wq, self.wk, self.wv, self.wo = [nn.Linear(d, d) for _ in range(4)]
        self.drop = nn.Dropout(dropout)

    def split(self, x: Tensor) -> Tensor:
        b, n, _ = x.shape
        return x.reshape(b, n, self.heads, self.dh).transpose(1, 2)

    def forward(self, query: Tensor, key: Tensor, value: Tensor,
                allow: Optional[Tensor] = None) -> Tensor:
        q, k, v = self.split(self.wq(query)), self.split(self.wk(key)), self.split(self.wv(value))
        out, _ = attention(q, k, v, allow,
                           dropout_p=self.drop.p, training=self.training)
        # Restore the token axis before combining the heads.
        out = out.transpose(1, 2).contiguous().reshape(query.size(0), query.size(1), -1)
        return self.wo(out)


class Position(nn.Module):
    def __init__(self, d: int, max_len: int = 128) -> None:
        super().__init__()
        if d % 2:
            raise ValueError('This simple sinusoidal implementation requires even d.')
        pos = torch.arange(max_len, dtype=torch.float32)[:, None]
        freq = torch.exp(torch.arange(0, d, 2, dtype=torch.float32) * (-math.log(10000.0) / d))
        pe = torch.zeros(max_len, d)
        pe[:, 0::2], pe[:, 1::2] = (pos * freq).sin(), (pos * freq).cos()
        self.register_buffer('pe', pe[None], persistent=False)

    def forward(self, x: Tensor) -> Tensor:
        if x.size(1) > self.pe.size(1):
            raise ValueError('Input is longer than the configured position buffer.')
        return x + self.pe[:, :x.size(1)].to(dtype=x.dtype)


def ffn(d: int) -> nn.Module:
    return nn.Sequential(nn.Linear(d, 4 * d), nn.ReLU(), nn.Linear(4 * d, d))


class EncoderBlock(nn.Module):
    def __init__(self, d: int, heads: int, dropout: float) -> None:
        super().__init__()
        self.self_attn = MultiHead(d, heads, dropout)
        self.ff = ffn(d)
        self.n1, self.n2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.drop = nn.Dropout(dropout)

    def forward(self, x: Tensor, allow: Tensor) -> Tensor:
        x = self.n1(x + self.drop(self.self_attn(x, x, x, allow)))
        return self.n2(x + self.drop(self.ff(x)))


class DecoderBlock(nn.Module):
    def __init__(self, d: int, heads: int, dropout: float) -> None:
        super().__init__()
        self.self_attn, self.cross = MultiHead(d, heads, dropout), MultiHead(d, heads, dropout)
        self.ff = ffn(d)
        self.n1, self.n2, self.n3 = nn.LayerNorm(d), nn.LayerNorm(d), nn.LayerNorm(d)
        self.drop = nn.Dropout(dropout)

    def forward(self, x: Tensor, memory: Tensor, target_allow: Tensor, source_allow: Tensor) -> Tensor:
        x = self.n1(x + self.drop(self.self_attn(x, x, x, target_allow)))
        x = self.n2(x + self.drop(self.cross(x, memory, memory, source_allow)))
        return self.n3(x + self.drop(self.ff(x)))


class TinyTransformer(nn.Module):
    def __init__(self, d: int = 64, heads: int = 4, layers: int = 2,
                 dropout: float = 0.1) -> None:
        super().__init__()
        self.d = d
        # Source/target share the same integer vocabulary in this toy task.
        self.embedding = nn.Embedding(VOCAB, d, padding_idx=PAD)
        self.pos, self.drop = Position(d), nn.Dropout(dropout)
        self.encoder = nn.ModuleList([EncoderBlock(d, heads, dropout) for _ in range(layers)])
        self.decoder = nn.ModuleList([DecoderBlock(d, heads, dropout) for _ in range(layers)])
        self.output = nn.Linear(d, VOCAB)  # Deliberately not tied to embedding.

    def embed(self, ids: Tensor) -> Tensor:
        return self.drop(self.pos(self.embedding(ids) * math.sqrt(self.d)))

    def encode(self, source: Tensor) -> tuple[Tensor, Tensor]:
        if source.ndim != 2 or not bool(source.ne(PAD).any(dim=1).all()):
            raise ValueError('Source must be [B,S], with at least one non-PAD token per sample.')
        source_allow = source.ne(PAD)[:, None, None, :]  # [B,1,1,S]
        memory = self.embed(source)
        for block in self.encoder:
            memory = block(memory, source_allow)
        return memory, source_allow

    def decode(self, prefix: Tensor, memory: Tensor, source_allow: Tensor) -> Tensor:
        t = prefix.size(1)
        causal = torch.ones(t, t, dtype=torch.bool, device=prefix.device).tril()
        # True=allowed, and the diagonal is included because the target is shifted.
        target_allow = causal[None, None] & prefix.ne(PAD)[:, None, None, :]
        x = self.embed(prefix)
        for block in self.decoder:
            x = block(x, memory, target_allow, source_allow)
        return self.output(x)

    def forward(self, source: Tensor, prefix: Tensor) -> Tensor:
        return self.decode(prefix, *self.encode(source))

    @torch.no_grad()
    def generate(self, source: Tensor, max_new: int = 32) -> Tensor:
        self.eval()
        memory, source_allow = self.encode(source)
        out = torch.full((source.size(0), 1), BOS, dtype=torch.long, device=source.device)
        finished = torch.zeros(source.size(0), dtype=torch.bool, device=source.device)
        for _ in range(max_new):
            token = self.decode(out, memory, source_allow)[:, -1].argmax(dim=-1)
            token = torch.where(finished, torch.full_like(token, EOS), token)
            out = torch.cat([out, token[:, None]], dim=1)
            finished |= token.eq(EOS)
            if bool(finished.all()):
                break
        return out[:, 1:]


def make_batch(rng: random.Random, batch: int, lo: int, hi: int,
               device: torch.device) -> tuple[Tensor, Tensor, Tensor]:
    seqs = [[rng.randrange(3, VOCAB) for _ in range(rng.randint(lo, hi))] for _ in range(batch)]
    width = max(map(len, seqs)) + 1
    src = torch.full((batch, width), PAD, dtype=torch.long)
    prefix, labels = torch.full_like(src, PAD), torch.full_like(src, PAD)
    for i, values in enumerate(seqs):
        rev = values[::-1]
        n = len(values) + 1
        src[i, :n] = torch.tensor(values + [EOS])
        prefix[i, :n] = torch.tensor([BOS] + rev)
        labels[i, :n] = torch.tensor(rev + [EOS])
    return src.to(device), prefix.to(device), labels.to(device)


def trim(row: list[int]) -> list[int]:
    if EOS in row:
        row = row[:row.index(EOS) + 1]
    return [x for x in row if x != PAD]


@torch.no_grad()
def evaluate(model: TinyTransformer, rng: random.Random, device: torch.device,
             lo: int, hi: int, batches: int = 3) -> dict[str, float]:
    model.eval()
    loss_sum = valid = correct = exact = total = 0
    for _ in range(batches):
        src, prefix, target = make_batch(rng, 24, lo, hi, device)
        logits = model(src, prefix)
        loss_sum += float(F.cross_entropy(logits.reshape(-1, VOCAB), target.reshape(-1),
                                         ignore_index=PAD, reduction='sum'))
        keep = target.ne(PAD)
        valid += int(keep.sum())
        correct += int((logits.argmax(-1).eq(target) & keep).sum())
        generated = model.generate(src, max_new=hi + 3)
        exact += sum(trim(a) == trim(b) for a, b in zip(generated.tolist(), target.tolist()))
        total += src.size(0)
    return {'nll': loss_sum / valid, 'teacher_forced_token_accuracy': correct / valid,
            'greedy_exact_match': exact / total, 'examples': total}


def checks(device: torch.device) -> dict[str, str]:
    torch.manual_seed(7)
    q, k, v = [torch.randn(2, 2, 5, 4, device=device) for _ in range(3)]
    mask = torch.ones(5, 5, dtype=torch.bool, device=device).tril()[None, None]
    out, a = attention(q, k, v, mask)
    assert out.shape == (2, 2, 5, 4)
    torch.testing.assert_close(a.sum(-1), torch.ones_like(a.sum(-1)))
    assert float(a.masked_select(~mask.expand_as(a)).abs().max()) == 0.0
    ref = F.scaled_dot_product_attention(q, k, v, attn_mask=mask, dropout_p=0.0)
    torch.testing.assert_close(out, ref, atol=2e-6, rtol=2e-5)
    # Pure self-attention is permutation-equivariant without positions/masks.
    mha = MultiHead(8, 2).to(device).eval()
    x = torch.randn(2, 5, 8, device=device)
    perm = torch.tensor([3, 0, 4, 1, 2], device=device)
    torch.testing.assert_close(mha(x[:, perm], x[:, perm], x[:, perm]),
                               mha(x, x, x)[:, perm], atol=2e-6, rtol=2e-5)
    # Cross-attention output follows the query length, not the memory length.
    assert mha(x[:, :3], x, x).shape == (2, 3, 8)
    # Masking a key makes its value irrelevant to the output.
    keep = torch.tensor([True, True, True, True, False], device=device)[None, None, None]
    v2 = v.clone(); v2[:, :, -1] += 100
    torch.testing.assert_close(attention(q, k, v, keep)[0], attention(q, k, v2, keep)[0])
    # In a full model, modifying future target input cannot affect earlier logits.
    model = TinyTransformer(d=16, heads=2, layers=1, dropout=0.0).to(device).eval()
    src = torch.tensor([[3, 4, 5, EOS]], device=device)
    prefix = torch.tensor([[BOS, 5, 4, 3]], device=device)
    changed = prefix.clone(); changed[:, 2:] = torch.tensor([8, 9], device=device)
    torch.testing.assert_close(model(src, prefix)[:, :2], model(src, changed)[:, :2],
                               atol=3e-6, rtol=2e-5)
    # A single backward pass confirms a working gradient path.
    model.train()
    logits = model(src, prefix)
    labels = torch.tensor([[5, 4, 3, EOS]], device=device)
    loss = F.cross_entropy(logits.reshape(-1, VOCAB), labels.reshape(-1))
    loss.backward()
    assert model.encoder[0].self_attn.wq.weight.grad is not None
    assert torch.isfinite(loss)
    return {name: 'PASS' for name in [
        'shape', 'row_sum_before_dropout', 'future_weight_zero', 'sdpa_reference',
        'permutation_equivariance', 'cross_query_length', 'masked_value_independence',
        'full_model_causal_invariance', 'backward_gradient']}

부품을 공유하지만 attention mask, 학습 목표, 위치 표현, 정규화, output head와 학습 데이터가 함께 달라집니다. 특히 원형 Decoder에는 self-attention + cross-attention + FFN이 있지만, 일반적인 순수 텍스트 Decoder-only block은 causal self-attention + FFN 중심입니다.

BERT의 masked language modeling도 “미래 정답을 보고 다음 토큰을 예측한다”는 누출과 다릅니다. 입력에서 가린 위치를 복원하는 별도 목표입니다. 어떤 정보가 입력이고 무엇이 예측 정답인지를 기준으로 판별합니다. [31 · §3]

ViT: 무엇을 token이라고 부를 것인가

이미지를 patch로 나누고 각 patch를 벡터로 투영하면 시퀀스처럼 Transformer에 넣을 수 있습니다. 가령 224×224 이미지를 16×16 patch로 나누면 14×14=196개 patch입니다. CLS 사용·positional embedding·pooling은 모델별로 확인합니다. 모든 Vision Transformer나 VLM Vision Encoder가 CLS를 갖는 것은 아닙니다. ViT 원논문 예시와 보편적 구조를 분리합니다. [34 · §3]

DiT: 같은 block, 다른 생성 과정

Diffusion의 DiT는 noisy latent patch와 timestep, 조건 정보를 받아 denoising에 필요한 값을 예측합니다. 원형 DiT는 class conditioning을 다루며 conditioning 방식도 여러 형태를 비교합니다. 따라서 모든 DiT가 텍스트를 입력받거나 cross-attention을 사용한다고 말하면 부정확합니다. 토큰 위치, Transformer layer 깊이, denoising timestep은 서로 다른 축입니다. [41 · §3]

서로 다른 길이를 묶기 위해 넣는 채움 값. Attention과 loss에서 적절히 제외해야 합니다.
Parameter
학습으로 갱신되는 모델의 수. 입력별로 계산되는 activation과 구분합니다.
Perplexity
평균 음의 로그 가능도에 exp를 적용한 수치. Tokenizer·평가 조건이 같아야 비교가 명확합니다.
Position encoding
token의 위치·순서를 계산에 반영하기 위한 정보. 원형은 sin/cos를 더합니다.
Residual connection
이전 표현에 sublayer 결과를 더하는 우회 연결.
Self-attention
Q/K/V를 동일한 시퀀스 표현에서 만드는 Attention.
Softmax
점수들을 양수이고 합이 1인 비중으로 바꾸는 함수. 정규화할 축을 확인해야 합니다.
Teacher forcing
학습 때 이전 예측 대신 이전 정답을 다음 단계의 조건으로 제공하는 방식.
Token
모델이 처리하는 기본 위치 단위. 단어·subword·문자·이미지 patch 등으로 구성할 수 있습니다.
Weight tying
서로 다른 모듈에서 동일한 학습 파라미터를 공유하는 설계.
Warm-up
학습 초기에 learning rate를 작은 값에서 점진적으로 증가시키는 schedule.
BOS / EOS / PAD
시작·종료·채움을 표현하는 특별 token의 역할. 실제 문자열·ID는 tokenizer에 따라 다릅니다.

역할이 달라 같은 단어라도 확인할 것

Layer는 문헌마다 Transformer block 전체 또는 개별 선형·정규화 층을 뜻할 수 있습니다. “몇 번째 layer”라고 말할 때는 block index인지 sublayer인지, 0-based인지 1-based인지 함께 명시합니다.

Attention weight는 학습 파라미터가 아니라 입력별 A를 뜻하는 경우가 많습니다. GQA는 여기서는 Grouped-query Attention이며, 시각 질의응답 데이터셋의 같은 약자와 구분합니다. Token은 문자열 조각일 수도 이미지 patch 표현일 수도 있습니다. 이름보다 입력·출력·shape를 먼저 확인합니다.
