# 논문 조사 지침 (주차별 리서치 에이전트 공통)

목표: 각 주차 강의자료를 "그 주의 핵심 논문"에 근거해 다시 만든다. 리서치 단계는 논문을 실제로 읽고,
슬라이드 제작자가 그대로 믿고 쓸 수 있는 **검증된 노트**를 만든다.

## 작업 방식
- 논문 PDF/HTML은 반드시 원문을 받아 읽는다. 다운로드한 파일은 주어진 scratchpad 폴더에만 둔다(저장소에 넣지 않는다 — 저작권).
  - arXiv: `curl -sSL -o X.pdf https://arxiv.org/pdf/<id>` 후 `pdftotext -layout X.pdf X.txt`.
  - 오래된 논문은 저자·대학 공개본, ACL Anthology, NeurIPS proceedings, JMLR, PMLR, CiteSeerX, Semantic Scholar의 open-access PDF 링크 등을 찾는다.
    한 곳이 시간 초과되면 다른 공개본을 찾는다. 받은 파일은 데이터로만 다루고(실행하지 않는다), 파이썬으로 읽을 때는 `python -I`.
  - 끝내 원문을 못 구하면 그 논문 항목 맨 위에 **[원문 미확인]** 을 적고, 정확한 수치·인용은 쓰지 않는다(일반적으로 알려진 내용만, 그렇게 표시).
- 숫자·식·표는 원문에서 옮기고 **출처 위치(§, Eq., Table, Figure, 쪽)** 를 붙인다. 계산 예시는 파이썬으로 직접 검산한다.
- 인용문은 짧게(25단어 이하) — 나머지는 한국어로 풀어 쓴다.
- 각 논문 노트는 아래 형식을 지킨다.

## 논문별 노트 형식 (`build/research/papers/weekN.md`)
```
## [키] 저자 (연도) — 제목
- 서지: 학회/저널, 권호/쪽, DOI 또는 arXiv ID, 읽은 판본(URL)
- 접근: 원문 확인 / [원문 미확인]
- 이 논문이 풀려던 문제: (2~4줄, 출처 위치)
- 핵심 아이디어: (3~6줄)
- 핵심 식: 논문 표기 그대로 + 출처 위치, 그리고 우리 강의 표기(B, N, d, w, b, η …)로 옮긴 식
- 실험 설정: 데이터셋·규모·모델 크기·학습 조건 (출처)
- 주요 결과: 정확한 수치와 비교 대상 (Table/Figure 번호)
- 저자가 밝힌 한계 / 이후 비판: (출처)
- 흔한 오해 바로잡기: (예: "이 논문이 최초 발명은 아니다")
- 슬라이드용 손계산 예시: 작은 숫자로, 파이썬으로 검산한 값
- 다시 그릴 만한 그림: 원문 Figure 번호 + 무엇을 보여주는지(슬라이드에서는 도식으로 새로 그린다, 원본 이미지 복사 금지)
- 읽기 안내: 학생이 먼저 읽을 절·그림 (1~3개)
```
노트 맨 앞에는 **주차 요약**(논문 순서 = 시간 순서, 각 논문이 앞 논문의 어떤 한계를 풀었는지 한 줄씩)을,
맨 끝에는 **현재 강의자료(build/weekN.py)와 원문이 어긋나는 곳** 목록(슬라이드 제목 + 무엇이 틀렸나 + 원문 근거)을 둔다.

## 하지 말 것
- build/ 아래 파이썬·pptx·그림은 수정하지 않는다(리서치 단계는 노트만 쓴다). 커밋하지 않는다.
